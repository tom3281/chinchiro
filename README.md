# チンチロ — 飲みゲーム版

スマホ1台あれば回しながら遊べる、3Dサイコロ付きの飲みゲーム。
親子の概念はなし、**全員順番に振って一番弱い1人が飲む**シンプルルール。

## 遊び方

1. 人数（2〜6人）と名前を設定 → 「対局開始」
2. ターン交代インタースティシャル（タップして次のプレイヤーへ）
3. 全員振り終わったら結果モーダル — 一番弱かった人が飲む
4. 局を重ねて累計杯数で笑う

## 役（強い順）

| 役 | 内容 | 杯数 |
| --- | --- | --- |
| ピンゾロ | 1-1-1 | 5杯 |
| ゾロ目 | 同じ目3つ | 3杯 |
| シゴロ | 4-5-6 | 2杯 |
| 1〜6の目 | 同じ目2つ + 他1つ（他の数字を採用） | 1杯 |
| 目なし | 3回振っても何も出ず | ハズレ |
| ヒフミ | 1-2-3 | ハズレ（最弱） |

* その局で出た**最強役の倍率**で最弱の人が飲む
* 最弱が複数いたらランダムで1人

## 動かす

`index.html` をブラウザで開くだけ。スマホで遊ぶときはローカルサーバー越しに：

```bash
cd chinchiro
python -m http.server 8000
# 同じWi-Fi内のスマホから http://<PCのIP>:8000 にアクセス
```

CDN（jsdelivr）から Three.js と cannon-es を取りに行くのでネット接続が必要です。

## デプロイ

ビルド不要なのでGitリポジトリをそのまま [Cloudflare Pages](https://pages.cloudflare.com) や [Vercel](https://vercel.com) に繋げば公開できます。ビルドコマンド空欄、出力ディレクトリも空欄（or `/`）でOK。

## 技術

- [Three.js](https://threejs.org/) — 3D描画（茶碗のLatheGeometry、サイコロのCanvasTextureで作ったピップ）
- [cannon-es](https://github.com/pmndrs/cannon-es) — 物理シミュ（重力・反発・摩擦）
- Vanilla JS, ES Modules, 単一HTMLファイル
- Web Audio APIで効果音合成、`navigator.vibrate` で振動
